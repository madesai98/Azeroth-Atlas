**Azeroth Atlas** for Windows: a 3D map of the WoW Forever world, built from your own installed game.

1. Download **Azeroth-Atlas-win-x64.zip** below and unpack it somewhere of your own (your Documents or Desktop: not Program Files, and not inside the game's folder).
2. Open the folder and double-click **Azeroth Atlas.exe**. Windows may say it protected your PC, because the program is not signed: **More info → Run anyway**.
3. The game is found by itself (or you are asked where it is). Press **Build map**: the first build reads the whole world out of your game and takes a good while.
4. Under **You**, press **Install addon** and restart the game.

Nothing else needs installing, and nothing of the game is in the download. The map tool keeps itself up to date from then on.
