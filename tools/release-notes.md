**Azeroth Atlas** for Windows: a 3D map of the WoW Forever world, built from your own installed game.

**Download `Azeroth-Atlas-Setup.exe` below and run it.** It installs for you alone, with no questions and no administrator rights, puts Azeroth Atlas in your Start menu and on your desktop, and opens it. Windows may say it protected your PC, because the program is not signed: **More info → Run anyway**.

Then, in the window that opens:

1. The game is found by itself (or you are asked where it is). Press **Build map**: the first build reads the whole world out of your game and takes a good while.
2. Under **You**, press **Install addon** and restart the game.

Nothing else needs installing, and nothing of the game is in the download. The map tool keeps itself up to date from then on.

*Rather not install anything?* `Azeroth-Atlas-win-x64.zip` is the same application as a folder: unpack it somewhere of your own (not Program Files, not the game's folder) and double-click **Azeroth Atlas.exe**.
